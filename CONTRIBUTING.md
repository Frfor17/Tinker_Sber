Краткое описание структуры репозитория и какие, для начала, Pull Request можно(но не только эти) сделать

1. Структура репо

- 3d_models: модели для печати, дизайн робота
- RL: reinforcement learning для ходьбы
- electronics: электроника\платы
- firmware: прошивка

2. Изменения, которые мы хотим

Perfomance\refactor: Сделаь код более производительным. Внедрить алгоритмы, переписать функции и системы, добиться любого улучшения производительности

Code improvement: Делать код более удобным для разработки, внедрения модульности, более простым, читабельным, более рабочим и лучше используемым. Допустим, добавление проверок для corner cases

Fix: починка багов

Quality of Life: повышение качества жизни разработки, использования. К примеру, сделать простую визуальную wireless интерфейс для управления роботом и тестирования\дебага

Features: добавления нового функционала, которые можно реализовать во взаимодействие с роботом

Documentation: Добавить больше документации для понимания репо другими

Hardware\Mechanical design: Добавить свои предложения по платам\электронике & дизайню деталей\рук\ног\сенсоров
